## GifTrim 0.1.1 — 检查更新 / Update check

### 新增 / New

- **检查更新 / Check for updates**：菜单「GifTrim → 检查更新…」，或在设置 → 更新里手动检查
  Menu "GifTrim → 检查更新…", or Settings → 更新
- **启动时自动检查 / Check at launch**：默认开启，可在设置里关闭；只在有新版本时提示
  On by default, can be turned off in Settings; only speaks up when a new version exists
- **一键升级 / One-click install**：下载新版 DMG，校验签名后替换当前 App 并重新打开
  Downloads the new DMG, verifies the signature, replaces the app and relaunches

> 0.1.0 没有检查更新功能，请手动安装本版本一次，之后即可在应用内升级。
> 0.1.0 has no updater; install this version by hand once, later versions can be installed from inside the app.

### 安装 / Install

```bash
brew install --cask swsususu/tap/giftrim
```

或下载下方的 `GifTrim_0.1.1_universal.dmg`。应用尚未公证，首次打开请右键 → 打开，或执行
`xattr -dr com.apple.quarantine /Applications/GifTrim.app`。
