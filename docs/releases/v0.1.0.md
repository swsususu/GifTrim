## GifTrim 0.1.0 — 首个版本 / First release

开源、免费的 macOS GIF 制作工具，GIF Brewery 的替代品，**同时也能交给 AI 助手来用**。
A free, open-source GIF maker for macOS, a GIF Brewery replacement, and **one your AI assistant can drive too**.

![GifTrim](https://raw.githubusercontent.com/swsususu/GifTrim/v0.1.0/docs/images/demo.gif)

### 亮点 / Highlights

- **高质量、小体积 / Sharp and small**：使用 gifski 编码，跨帧调色板优化，每帧可用上千种颜色
  gifski encoder with a cross-frame palette, so frames get thousands of colors
- **所见即所得 / WYSIWYG**：预览就是最终 GIF，显示真实大小；也可以按目标大小（例如 ≤ 2 MB）自动选择宽度
  The preview is the real GIF with its real size; auto-fit to a target size
- **录制 / Record**：屏幕区域、摄像头、Continuity Camera，以及 USB 连接的 iPhone / iPad 屏幕
  Screen region, webcam, Continuity Camera, or an iPhone/iPad over USB
- **编辑 / Edit**：截取、裁剪（锁定比例）、多段字幕、贴图水印、13 种滤镜、变速、倒放 / 来回、逐帧编辑
  Trim, crop with locked ratios, captions, stickers, 13 effects, speed, reverse/bounce, frame editor
- **🤖 AI 就绪 / AI-ready**
  - `giftrim mcp`：MCP 服务，提供 `get_media_info` / `preview_frame` / `estimate_gif` / `make_gif` 四个工具
    MCP server with four tools: `get_media_info`, `preview_frame`, `estimate_gif`, `make_gif`
  - `skills/giftrim`：Agent Skill，适用于 Claude Code、Codex 等
    Agent skill for Claude Code, Codex and others
  - 命令行全部支持 `--json`，也可以执行 JSON 任务（`giftrim run`）
    `--json` on every command, plus JSON jobs (`giftrim run`)
  - 配置方法见 [docs/AI.md](https://github.com/swsususu/GifTrim/blob/main/docs/AI.md)
    Setup guide in docs/AI.md

```bash
claude mcp add giftrim -- /Applications/GifTrim.app/Contents/Helpers/giftrim mcp
```

### 安装 / Install

```bash
brew install --cask swsususu/tap/giftrim
```

或者下载下方的 `.dmg`，把 GifTrim 拖进“应用程序”。
Or download the `.dmg` below and drag GifTrim to Applications.

应用尚未公证，第一次打开请右键点击选择“打开”，或者执行：
GifTrim is not notarised, so right-click → Open the first time, or run:

```
xattr -dr com.apple.quarantine /Applications/GifTrim.app
```

### 已知限制 / Known limitations

- 仅在 macOS 27 / Apple Silicon 上实机验证过；Intel 版在 Rosetta 下能启动，但未在真机测试
  Verified on macOS 27 / Apple Silicon; the Intel build launches under Rosetta but is untested on hardware
- App 界面目前以中文为主；命令行、MCP 和文档提供英文
  The app UI is Chinese-first; CLI, MCP and docs are in English
- 应用为 ad-hoc 签名，每次更新后可能需要重新授予录屏权限
  Ad-hoc signed, so screen-recording permission may need re-granting after updates
