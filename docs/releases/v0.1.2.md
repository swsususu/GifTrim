## GifTrim 0.1.2 — 稳定性修复 / Stability fixes

### 导出 / Export

- 修复部分 HEVC 视频（如 VideoToolbox 编码的 60fps 录屏）导出到片尾时报“Cannot Decode”
  Fixed "Cannot Decode" when exporting some HEVC videos up to their last frame
- 修复 GIF 最后一帧时长错误（单张图片只有 20ms、动图总时长变短）
  The last frame now keeps its own delay (single images no longer last 20 ms)
- 输出路径为目录或与输入为同一文件时直接报错，不再删除/覆盖；导出先写临时文件，失败不会破坏已有文件
  Refuses directory outputs and outputs that equal an input; writes atomically
- 输出目录无写权限时不再崩溃
  No longer crashes when the output folder is not writable

### 编辑器 / Editor

- 时间轴左侧手柄拖不动的问题
  The left trim handle can be dragged reliably
- 打开/保存面板中按键不再误改截取范围；Caps Lock 开启时快捷键可用
  Shortcuts no longer fire inside open/save panels and work with Caps Lock on
- 预览静音，预览速度与导出一致（最高 4x），29.97fps 逐帧更准
  Muted preview, preview speed matches export, accurate frame stepping
- “拷贝”后关闭窗口文件不丢失；预览临时文件会清理；保存失败会提示
- 锁定比例裁剪拖到边缘不再跳位

### 录制 / Recording

- 录屏连点停止、摄像头被占用时不再崩溃；录屏末尾静止画面不再被截掉

### 命令行与 MCP / CLI & MCP

- 参数缺值、重复、未知参数给出明确错误；`--json` 下错误也只输出一个 JSON 对象；`--help` 退出码 0
- `run`/MCP 拒绝 schema 中不存在的字段；MCP 取消后不再留下残缺 GIF
- `giftrim --version` 显示正确版本

### 更新 / Updater

- 应用内升级改为原子替换（失败可恢复），并校验 bundle id、版本号和 SHA-256

### 安装 / Install

```bash
brew upgrade --cask giftrim   # or: brew install --cask swsususu/tap/giftrim
```

或下载下方的 `GifTrim_0.1.2_universal.dmg`。应用尚未公证，首次打开请右键 → 打开，或执行
`xattr -dr com.apple.quarantine /Applications/GifTrim.app`。
